Upload expert / LoRA

Contribute an expert through GitHub. Store the weights on Hugging Face and add a small reference package to Git.

  1. Copy experts/_template to experts/qwen35-9b/<expert_id>.
  2. Fill in expert.json, prompt.txt, and README.md. In lora.json, add the Hugging Face URL, file paths, and pinned commit SHA.
  3. Run python scripts/validate_experts.py and submit the folder through GitHub. Keep large weight files out of Git.
  4. After the contribution is merged, pull the update and restart GhostSwitch. Select Download and enable in the library.
