# Trademark distinctiveness classification (Qwen3.5-4B)

Classifies a trademark on the Generic, Descriptive, Suggestive, Arbitrary, or Fanciful Abercrombie spectrum, given the mark and its goods or services.

Source: https://huggingface.co/DoodDood/abercrombie-grpo

Revision: `d575839ab404e3104179d800e6dfe7e45af20253`. Check the source model card for license, training data, limitations, and usage terms before redistribution or use. This package contains metadata only; weights are fetched on demand. It was migrated from the archived Qwen3.5-4B registry in `versions/legacy-4b`. No independent quality claim is made.

## Examples

Use for: Classify the mark 'Apple' for computers on the Abercrombie spectrum.

Not for: Draft a full trademark registration filing.

Output language follows the user; the source training language does not override it.
